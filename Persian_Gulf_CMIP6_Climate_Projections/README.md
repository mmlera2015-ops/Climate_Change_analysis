# Climate Change Projections for the Persian Gulf Region Using CMIP6 Scenarios

**Prepared by:** Leila Rashidian

## Project Overview

This project presents climate projection diagrams for the Bushehr area of the Persian Gulf region, developed using CMIP6 climate scenarios. The figures provide a visual overview of projected changes in selected climate variables under different scenario pathways.

## Study Area

The analysis focuses on Bushehr, located on the northern coast of the Persian Gulf, Iran.

## Data and Approach

The project uses CMIP6 scenario-based climate projection outputs. The accompanying PDF contains the curated diagrams prepared for public scientific communication.

## Notes and Limitations

The diagrams should be interpreted in the context of the selected climate models, scenarios, variables, temporal periods, and spatial coverage used in the underlying analysis. They do not represent station observations or deterministic predictions.

Raw datasets and sensitive station-location information are not included in this public repository.
